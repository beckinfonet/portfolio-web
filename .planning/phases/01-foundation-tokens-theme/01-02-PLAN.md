### `@theme` token contract (UI-SPEC §"globals.css @theme skeleton (binding shape)")

Token names and namespaces generate Tailwind v4 utilities automatically:
- `--color-background` → `bg-background`, `text-background`, `border-background`
- `--color-surface` → `bg-surface`
- `--color-border` → `border-border`
- `--color-text-primary` → `text-text-primary`
- `--color-text-secondary` → `text-text-secondary`
- `--color-accent` → `bg-accent`, `text-accent`, `ring-accent`
- `--text-caption` → `text-caption` utility
- `--text-body` → `text-body`
- `--text-lg` → `text-lg` (overrides Tailwind default)
- `--text-h4` → `text-h4`
- `--text-h3` → `text-h3`
- `--text-h2` → `text-h2`
- `--text-h1` → `text-h1`
- `--text-display` → `text-display`
- `--text-mono-sm` → `text-mono-sm`
- `--text-mono-base` → `text-mono-base`
- `--font-sans` → `font-sans` utility uses var(--font-geist-sans)
- `--font-mono` → `font-mono` utility uses var(--font-geist-mono)

### `src/lib/tokens.ts` export shape (UI-SPEC §"src/lib/tokens.ts")

```ts
export const tokens = {
  light: { background: "#ffffff", textPrimary: "#0a0a0a", textSecondary: "#525252", accent: "#0057ff" },
  dark:  { background: "#0a0a0a", textPrimary: "#fafafa", textSecondary: "#a3a3a3", accent: "#4d8bff" },
} as const;
```
