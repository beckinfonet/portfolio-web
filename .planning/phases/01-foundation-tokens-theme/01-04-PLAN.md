          - name: TypeScript typecheck
            run: npm run typecheck

          - name: Build
            run: npm run build

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → GITHUB_TOKEN | Workflow has access to a repo-scoped token; least-privilege reduces blast radius |
| CI runner → npm registry | Installs deps from the public registry; `npm ci` + lockfile freeze what's fetched |
| Contributor push → main branch | Only green CI should land on main (branch protection is a GitHub setting, not a workflow file — recommend user configures) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-14 | Elevation of Privilege | `GITHUB_TOKEN` default permissions | mitigate | `permissions: contents: read` at workflow level — workflow cannot push, comment, or modify anything. Asserted by `grep 'contents: read'` in Task 1 acceptance criteria |
| T-01-15 | Tampering (supply chain) | npm install on CI runner | mitigate | `npm ci` (not `npm install`) with committed `package-lock.json` — byte-identical to local install. Asserted in Task 1 acceptance criteria |
| T-01-16 | Denial of Service (CI minute exhaustion) | Multiple pushes to same branch trigger overlapping runs | mitigate | `concurrency` block cancels in-progress runs when a new push arrives. Asserted in Task 1 acceptance criteria |
| T-01-17 | Information Disclosure | Workflow logs leak secrets | accept (low risk in Phase 1) | No `secrets.*` referenced in workflow; no env vars set. When Phase 7 adds deploy tokens, that workflow's threat model revisits secret handling |
| T-01-18 | Spoofing (workflow identity) | Pinned action versions prevent a malicious action update from silently executing new code | mitigate | `actions/checkout@v4` and `actions/setup-node@v4` — pinned to major (v4). Full SHA pinning is overkill for Phase 1 (Vercel Security Advisory threshold); recommend revisiting for Phase 7 deploy workflow |
